# Soil Assessment Frontend

Frontend application for the **AI-Based Soil Assessment and Crop Recommendation System**.

## Project Overview

This research project uses Artificial Intelligence, Machine Learning, and Image Processing techniques to analyze soil conditions and provide intelligent recommendations for agricultural decision-making.

## Main Components

1. Soil Fertility & Nutrition Prediction
2. Crop Recommendation
3. Fertilizer Recommendation
4. Soil Classification
